Announce say something to everyone in game chat

Announcements are HTML-escaped before they are sent. The client renders chat with innerHTML, so this is what stops a message becoming script injection in every connected browser.

Match

Everyone

“Gather” pulls everyone to spawn 0 in a ring so they do not land inside one another. “Slap” is the grenade impulse path, so the client reconciles it as ordinary knockback instead of snapping.

Presets one click, several settings

Presets go through the ordinary settings path, so bounds, the change log and persistence all behave exactly as if each value had been typed by hand.

Map

Maps are downloaded from ev.io on first use and cached on disk, so nothing large ships with the server. ● marks maps already cached (instant). Switching reloads the map for every connected player and starts a fresh round.
